# hello-claude

## Objetivo
Projeto de estudo para aprender o básico de Node.js e Claude Code.

## Stack
JavaScript com Node.js, sem bibliotecas externas.

## Comandos
- Executar: `node hello.js`

## Convenções
- Comentários no código em português.
- O usuário é iniciante: antes de aplicar uma mudança, explique de forma simples o que será feito e por quê.

## Decisões
- 2026-10-07: data e hora formatadas com `toLocaleString("pt-BR")` e fuso `America/Sao_Paulo`, para mostrar sempre o horário de Brasília sem depender de bibliotecas.
